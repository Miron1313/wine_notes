# 🍷 와인노트: WSET Level 2 테이스팅 기록장

WSET Level 2 SAT(Systematic Approach to Tasting) 기준으로 마신 와인을 기록하고 공부하는 모바일 웹앱(PWA)입니다.
서버 없이 폰 안(IndexedDB)에 저장되고, 홈 화면에 설치하면 오프라인에서도 동작합니다.

## 기능
- **SAT 선택형 입력**: Appearance, Nose, Palate, Conclusions를 WSET 영문 용어 칩으로 입력 (한글 힌트 포함)
- **Wine-Lexicon 아로마 칩**: 1차/2차/3차 분류 + 직접 입력, 향에서 고른 것을 풍미로 가져오기
- **블라인드 모드**: 품종·국가·산지·빈티지대·가격대를 추론 → 정답 공개 → 자동 채점(직접 수정 가능)
- **통계**: 블라인드 항목별 적중률과 추이, 품종별 구조감 평균, 자주 쓴 아로마, 품질 분포
- **비교**: 2~4개 기록 또는 같은 품종 기록을 나란히 비교 (다른 값 강조)
- **부가 정보**: 라벨 사진(자동 압축), 가격·구매처, 날짜·장소·함께한 사람, 별점·재구매 의사
- **백업**: JSON 백업/복원(병합), CSV 내보내기, 2주마다 백업 알림
- **언어 선택**: 한국어 · English · Русский (상단 🌐 또는 설정). SAT 용어는 항상 영어 원문이고, 한국어·러시아어에서는 작은 번역 힌트가 함께 표시됩니다
- **가격**: 원화(₩)로 입력·표시합니다. 숫자 형식만 언어에 맞춰 바뀝니다
- **Level 2 진도**: 8대 주요 품종(샤르도네는 서늘한 기후·따뜻한 기후·오크 숙성으로 나눠서), 스파클링(전통·탱크 방식), 주정강화(셰리·포트), 지역 주요 품종을 기록에서 자동으로 체크
- **구매 판정·핵심 배움**: 강력추천/추천/조건부/비추천 판정과 "핵심 배움 1줄"을 기록마다 남김
- **시음기록 파일(.md)**: 진도 체크와 기록 표를 Claude 프로젝트 파일 형식 그대로 내보내기 (통계 또는 설정 화면)
- **월 예산·지출**: 설정에서 월 예산을 정하고, 기록마다 "구매 금액(내가 쓴 돈)"을 넣으면 차감. 남은 금액은 "○월 이월금액"으로 다음 달에 넘어가고 가장 오래된 이월금액부터 차감. 통계에서 이번 달 남은 예산, 이번 달·올해·전체 지출, 월별 지출 확인
- **원인 → 결과**: 기후·양조(오크·MLF·앙금 등)·숙성을 고르면 교과서적 결과를 보여주고 내 노트와 일치하는지 표시
- **라벨 용어 사전**: 원산지 등급·독일 프레디카트·숙성 표기·스파클링 당도·셰리/포트 등 약 55개 용어 (3개 언어). 기록에 고른 용어는 뜻과 함께 저장
- **다음에 마실 병**: 진도를 보고 안 마신 품종·빈 칸·대조 시음을 대표 산지와 함께 추천
- **퀴즈**: 라벨 용어·산지·아로마·원인→결과·내 기록에서 자동 생성한 객관식 10문제. 틀린 문제는 맞힐 때까지 복습 목록에 남음 (통계 맨 위 🧠 버튼)
- **전형성 체크**: 8대 품종 기록에서 내 구조감·아로마를 교과서 대표 프로필과 비교

## 사용 방법
1. GitHub Pages 주소를 폰에서 엽니다.
2. 홈 화면에 추가합니다.
   - iPhone: Safari 공유 버튼 → "홈 화면에 추가" (**iPhone은 꼭 추가해야 데이터가 오래 보존됩니다**)
   - Android: Chrome 메뉴 → "앱 설치"
3. 하단 ＋ 버튼 → 새 테이스팅 또는 블라인드 테이스팅
4. 백업 탭에서 정기적으로 JSON 백업 → 파일 앱/구글 드라이브에 보관

## GitHub Pages 배포 (최초 1회)
1. 레포 Settings → General → Danger Zone → **Change visibility → Public**
   (무료 플랜 Pages 조건. 공개되는 것은 코드뿐이고, 기록 데이터는 각자의 폰에만 있습니다.)
2. Settings → **Pages** → Build and deployment → Source: **GitHub Actions**
3. 이 브랜치를 `main`에 병합하면 `.github/workflows/pages.yml`이 자동 배포합니다.
4. 주소: `https://miron1313.github.io/wine_notes/`

## 로컬 실행
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
빌드 도구는 필요 없습니다 (순수 HTML/CSS/JS 모듈).

## 파일 구조
| 경로 | 역할 |
|---|---|
| `index.html` | 앱 화면 틀 |
| `css/app.css` | 스타일 (라이트/다크 모드) |
| `data/wset-l2-sat.js` | **SAT 용어·Wine-Lexicon·품종·국가 목록**: 교재와 다르면 여기만 수정 |
| `data/i18n.js` | 화면 문구 번역 (한국어·영어·러시아어) |
| `js/i18n.js` · `js/money.js` | 언어 선택 · 원화 가격 표시 |
| `js/app.js` | 라우터, 목록·상세·설정 화면 |
| `js/form.js` | 기록 입력·수정·정답 공개 화면 |
| `js/stats.js` | 통계·비교 화면 |
| `js/backup.js` | JSON/CSV/시음기록(.md) 내보내기·복원 |
| `js/progress.js` · `js/budget.js` | Level 2 진도 집계·시음기록 파일 · 월 예산·이월·지출 집계 |
| `js/study.js` · `data/label-terms.js` | 원인 → 결과, 전형성 체크, 다음 병 추천, 라벨 용어 사전 |
| `js/quiz.js` · `data/typical.js` | 퀴즈 · 8대 품종 대표 프로필과 산지 문제 |
| `js/model.js` | 데이터 구조, 블라인드 자동 채점 |
| `js/db.js` | IndexedDB 저장소 |
| `sw.js` | 오프라인 캐시 (앱 파일 수정 시 `VERSION` 올리기) |
